## 1. نظرة عامة على النظاةم

نظام كشف الغاز الصناعي عبارة عن منظومة متكاملة تعمل على محورين:

| المكون | المهمة |
|--------|--------|
| **STM32F103** | يقرأ أجهزة الاستشعار (ADC)، يتحكم في الريليهات والبيزر والـ LED، يرسل البيانات على RS485 |
| **Arduino Pro Mini** | يدير شاشة LCD، يستقبل ضغطات الأزرار، يرسل ويستقبل الإعدادات من STM32 عبر UART |

**الفكرة الأساسية:**
- Arduino هو واجهة المستخدم (شاشة + أزرار)
- STM32 هو المعالج الفعلي (قراءة حساسات + تشغيل ريليهات + إنذار)
- يتواصلان عبر سلك UART بسرعة 9600 baud

---

## 2. مكونات النظام

### أجهزة الاستشعار
- **عدد الحساسات:** 10 حساسات (S1 → S10)
- **نوعان مدعومان:**
  - `VOLT` — حساس جهد كهربي (0 → 5 فولت تقريباً)
  - `AMB`  — حساس تيار 4–20 مللي أمبير (كبير سلكي صناعي)

### الريليهات
- **عدد الريليهات:** 4 ريليهات (R1 → R4)
- كل حساس يمكن ربطه بريليه محدد
- الريليه يشتغل لما قراءة الحساس تتخطى الحد المضبوط

### واجهة المستخدم
- شاشة LCD 16×2 بعنوان I2C (0x27)
- 6 أزرار: أعلى / أسفل / يسار / يمين / OK / BACK
- بيزر صوتي للنقر عند الضغط على الأزرار
- 3 LEDs: أخضر / أصفر / أحمر

## 4. واجهة اللوحة والأزرار

### الأزرار وأرقام البنات (Arduino Pro Mini):

| الزر | البن | الوظيفة العامة |
|------|------|----------------|
| **UP** ↑ | Pin 9 | التمرير للأعلى / رفع قيمة |
| **DOWN** ↓ | Pin 11 | التمرير للأسفل / تخفيض قيمة |
| **LEFT** ← | Pin 12 | تغيير الخيار الأيسر |
| **RIGHT** → | Pin 7 | تغيير الخيار الأيمن |
| **OK** ✓ | Pin 6 | تأكيد / دخول |
| **BACK** ✗ | Pin 10 | رجوع / إلغاء |

> كل الأزرار تعمل بـ **Active-Low** مع مقاومة Pull-Up داخلية (INPUT_PULLUP).  
> ستسمع **نقرة صوتية** عند كل ضغطة صحيحة على البيزر.

## 5. الشاشة الرئيسية — عرض أجهزة الاستشعار

بعد انتهاء التسخين، تظهر الشاشة الرئيسية التي تعرض قراءات الحساسات:

### تنسيق العرض:

**لحساس VOLT (جهد):**
```
S1:3.24V R2
```
- `S1` = رقم الحساس
- `3.24V` = الجهد الحالي
- `R2` = الريليه المرتبط (R0 = بدون ريليه)

**لحساس AMB (تيار):**
```
S3:12.5mA R1
```
- `S3` = رقم الحساس
- `12.5mA` = التيار الحالي بالمللي أمبير
- `R1` = الريليه المرتبط

**لحساس معطل:**
```
S5: DISABLED
```

### التنقل في الشاشة الرئيسية:

| الزر | الفعل |
|------|-------|
| **UP** ↑ | عرض الحساسات السابقة في القائمة |
| **DOWN** ↓ | عرض الحساسات التالية في القائمة |
| **OK** في آخر سطر `[SETTINGS]` | الدخول لقائمة الإعدادات (يطلب كلمة سر) |

> الشاشة تعرض حساسَيْن في وقت واحد. لعرض باقي الحساسات اضغط ↑ أو ↓.  
> آخر سطر في القائمة هو `[ SETTINGS ]`.

## 6. الدخول على قائمة الإعدادات

### خطوات الدخول:

1. اضغط ↓ حتى تظهر `[ SETTINGS ]` في السطر الثاني
2. اضغط **OK**
3. ستظهر شاشة كلمة السر:

```
┌────────────────┐
│ENTER PASSWORD: │
│ Pass: [____]   │
└────────────────┘
```

### كيفية إدخال كلمة السر:

| الزر | الفعل |
|------|-------|
| **UP** ↑ | زيادة الرقم الحالي (+1، يدور من 9 لـ 0) |
| **DOWN** ↓ | تقليل الرقم الحالي (-1، يدور من 0 لـ 9) |
| **RIGHT** → | الانتقال للخانة التالية |
| **LEFT** ← | الرجوع للخانة السابقة |
| **OK** | تأكيد كلمة السر |
| **BACK** | إلغاء والرجوع للشاشة الرئيسية |

> **كلمة السر الافتراضية:** `1234`

**إذا كانت كلمة السر صحيحة:**
```
┌────────────────┐
│ SETTINGS MENU: │
│1. Sensor En/Dis│
└────────────────┘
```

**إذا كانت كلمة السر خاطئة:**
```
┌────────────────┐
│ WRONG PASSWORD │
│ Access Denied! │
└────────────────┘
← تعود للشاشة الرئيسية تلقائياً بعد 1.5 ثانية
```

## 7. إعدادات أجهزة الاستشعار

### الدخول: قائمة الإعدادات → اختار `1. Sensor En/Dis` → OK

```
┌────────────────┐
│ SENSOR 1 SETUP │
│VOLT RELAY: R1  │
└────────────────┘
```

### التنقل والتعديل:

| الزر | الفعل |
|------|-------|
| **UP** ↑ | الانتقال للحساس السابق |
| **DOWN** ↓ | الانتقال للحساس التالي |
| **LEFT** ← | تغيير وضع الحساس (يدور: DISABLED → VOLT → AMB → DISABLED) |
| **RIGHT** → | تغيير الريليه المرتبط (يدور: R1 → R2 → R3 → R4 → R1) |
| **OK** أو **BACK** | حفظ والرجوع لقائمة الإعدادات |

### أوضاع الحساس:

| الوضع | المعنى |
|-------|--------|
| `DISABLED` | الحساس معطل — لا يُقرأ ولا يُحسب |
| `VOLT` | حساس جهد كهربي (0–5V)، العتبة بالـ mV |
| `AMB` | حساس تيار صناعي 4–20 mA، العتبة بالـ mA |

> **🔄 مهم:** أي تغيير يتم إرساله فوراً لـ STM32 تلقائياً.

## 8. إعدادات الريليهات

### الدخول: قائمة الإعدادات → اختار `2. Relay Config` → OK

```
┌────────────────┐
│ RELAY 1 CONFIG │
│MODE: ACTIVE LOW│
└────────────────┘
```

### التنقل والتعديل:

| الزر | الفعل |
|------|-------|
| **UP** ↑ | الانتقال للريليه السابق |
| **DOWN** ↓ | الانتقال للريليه التالي |
| **LEFT** ← أو **RIGHT** → | تبديل وضع الريليه بين Active-Low و Active-High |
| **OK** أو **BACK** | حفظ والرجوع لقائمة الإعدادات |

### وضع الريليه:

| الوضع | المعنى |
|-------|--------|
| `ACTIVE LOW` | الريليه يشتغل لما الخرج = 0V (الغالب في الريليهات الصناعية) |
| `ACTIVE HIGH` | الريليه يشتغل لما الخرج = 3.3V |

> اختار الوضع حسب نوع لوحة الريليه اللي عندك.

## 9. الإعدادات المتقدمة — ضبط عتبات التشغيل

### الدخول: قائمة الإعدادات → اختار `3. Advanced Set` → OK

هنا بتضبط متى يُفعَّل الريليه لكل حساس. كل حساس عنده 3 معاملات:

```
┌────────────────┐
│ S1 ADV THRESH  │
│>Volt: 2.00V    │  ← الجهد (param 0)
└────────────────┘
```

### التنقل بين الحساسات:

| الزر | الفعل |
|------|-------|
| **UP** ↑ | الانتقال للحساس السابق |
| **DOWN** ↓ | الانتقال للحساس التالي |

### التنقل بين المعاملات (داخل نفس الحساس):

| الزر | الفعل |
|------|-------|
| **OK** | التنقل بين المعاملات (Volt → Perc → PPM → Volt ...) |

### تعديل القيمة الحالية (علامة `>` تشير للمعامل النشط):

| الزر | الفعل |
|------|-------|
| **RIGHT** → | زيادة القيمة |
| **LEFT** ← | تقليل القيمة |

### المعاملات الثلاثة:

| المعامل | الوحدة | خطوة التغيير | النطاق |
|---------|--------|-------------|--------|
| **Volt** (لـ VOLT) | mV | 100 mV | 0 – 5000 mV |
| **Volt** (لـ AMB) | mA | 5 mA | 0 – 1000 mA |
| **Perc** | % | 5% | 0 – 100% |
| **PPM** | PPM | 10 PPM | 0 – 1000 PPM |

**مثال للحساس VOLT:**
```
>Volt: 2.00V    ← لو الجهد ≥ 2V يشتغل الريليه
>Perc: 60%      ← (مستخدم للعرض فقط حالياً)
>PPM : 100 PPM  ← (مستخدم للعرض فقط حالياً)
```

**مثال للحساس AMB:**
```
>Curr: 12mA     ← لو التيار ≥ 12mA يشتغل الريليه
```

### إنهاء التعديلات:
اضغط **BACK** للرجوع لقائمة الإعدادات.

> **🔄 مهم:** كل تغيير في عتبة الحساس يُرسل فوراً لـ STM32.

## 11. إرسال القيم على RS485

النظام يرسل قراءات الحساسات تلقائياً على بروتوكول **RS485** (MAX485) بتردد كل **500ms**.

- **المنفذ:** USART3 على STM32
- **السرعة:** 115200 baud
- **الصيغة:** يُرسل فولت/تيار الحساسات العشرة كل دورة

> لا يحتاج المستخدم لفعل أي شيء — الإرسال تلقائي بعد اكتمال التهيئة.

## 12. استكشاف الأعطال

### المشكلة: الشاشة تقف عند `Wait for STM32` أكثر من 10 ثوان

**الأسباب المحتملة:**
- سلك UART بين Arduino و STM32 منفصل أو معكوس
- STM32 لم يُشغَّل بعد أو لم يُبرمج
- بنات SoftwareSerial خاطئة (يجب أن تكون: RX=Pin2, TX=Pin3)

**الحل:**
1. تأكد من توصيل TX-STM32 → RX-Arduino (Pin 2) وRX-STM32 → TX-Arduino (Pin 3)
2. تأكد أن STM32 شغال (يمكن استخدام شاشة Serial بـ 9600 baud)
3. أعد تشغيل الجهازين معاً

---

### المشكلة: الشاشة تقف عند `SYNCING CFG` ولا تكمل

**الأسباب المحتملة:**
- STM32 بيستقبل الإعدادات لكن مش بيرد بتأكيد (ACK)
- تداخل في الإشارات على UART

**الحل:**
- النظام يعيد الإرسال كل 3 ثواني تلقائياً
- لو استمرت المشكلة، أعد تشغيل الجهازين
- تحقق من أن UART1 على STM32 مضبوط على 9600 baud

---

### المشكلة: قراءات الحساسات تظهر صفر دائماً

**الأسباب المحتملة:**
- الحساس معطل (DISABLED)
- الحساس غير موصول بشكل صحيح
- خطأ في اختيار وضع الحساس (VOLT بدلاً من AMB أو العكس)

**الحل:**
1. ادخل إعدادات الحساسات وتأكد أنه `VOLT` أو `AMB` (مش `DISABLED`)
2. تحقق من توصيل سلك الحساس بـ ADC channel الصحيح
3. لحساسات AMB، تأكد أن التيار في النطاق 4-20 mA

---

### المشكلة: الريليه لا يشتغل رغم أن القراءة تخطت العتبة

**الأسباب المحتملة:**
- الحساس مش مربوط بريليه (Relay = NONE)
- وضع الريليه خاطئ (Active-Low بدلاً من Active-High أو العكس)
- العتبة مضبوطة بقيمة كبيرة جداً

**الحل:**
1. تحقق في إعدادات الحساس أن الريليه محدد (R1/R2/R3/R4)
2. غيّر وضع الريليه من إعدادات الريليه
3. خفّض قيمة عتبة الجهد/التيار من الإعدادات المتقدمة

---

### المشكلة: البيزر يرن باستمرار بدون سبب

**الأسباب المحتملة:**
- حساس ممكَّن لكن مش موصول (سلك مقطوع → قراءة خاطئة)
- العتبة مضبوطة بقيمة منخفضة جداً

**الحل:**
1. عطّل الحساسات غير الموصولة من إعداداتها (اضبطها `DISABLED`)
2. ارفع قيمة العتبة من الإعدادات المتقدمة

## 13. ملخص سريع للأزرار

### في الشاشة الرئيسية (Main Menu):

| الزر | الفعل |
|------|-------|
| ↑ UP | عرض الحساس السابق |
| ↓ DOWN | عرض الحساس التالي |
| OK (عند `[SETTINGS]`) | الدخول للإعدادات |

### في شاشة كلمة السر:

| الزر | الفعل |
|------|-------|
| ↑ UP | رفع الرقم |
| ↓ DOWN | تخفيض الرقم |
| → RIGHT | الخانة التالية |
| ← LEFT | الخانة السابقة |
| OK | تأكيد |
| BACK | رجوع |

### في قائمة الإعدادات (Settings Menu):

| الزر | الفعل |
|------|-------|
| ↑ UP | الاختيار السابق |
| ↓ DOWN | الاختيار التالي |
| OK | دخول الاختيار |
| BACK | رجوع للشاشة الرئيسية |

### في إعدادات الحساسات (Sensor Settings):

| الزر | الفعل |
|------|-------|
| ↑ UP | حساس سابق |
| ↓ DOWN | حساس تالي |
| ← LEFT | تغيير وضع الحساس (DISABLED/VOLT/AMB) |
| → RIGHT | تغيير الريليه المرتبط (R1→R4) |
| OK / BACK | رجوع |

### في إعدادات الريليه (Relay Settings):

| الزر | الفعل |
|------|-------|
| ↑ UP | ريليه سابق |
| ↓ DOWN | ريليه تالي |
| ← LEFT أو → RIGHT | تبديل Active-Low/High |
| OK / BACK | رجوع |

### في الإعدادات المتقدمة (Advanced Settings):

| الزر | الفعل |
|------|-------|
| ↑ UP | حساس سابق |
| ↓ DOWN | حساس تالي |
| OK | التنقل بين المعاملات (Volt/Perc/PPM) |
| ← LEFT | تقليل القيمة |
| → RIGHT | زيادة القيمة |
| BACK | رجوع |

## ⚡ بروتوكول الاتصال (للمبرمجين)

### من Arduino → STM32 (UART1, 9600 baud):

```json
// إعداد حساس واحد
{"type":"cfgs","i":0,"m":1,"r":0,"tv":2000,"tp":60,"tppm":100}
// i=رقم الحساس, m=الوضع, r=الريليه, tv=عتبة الجهد, tp=عتبة%, tppm=عتبة PPM

// إعداد الريليهات
{"type":"cfgr","r":[{"m":0},{"m":0},{"m":0},{"m":0}]}
// m=0 ACTIVE_LOW, m=1 ACTIVE_HIGH
```
